# 广州川将机电设备有限公司 · 企业官网

简洁大气的企业官网，展示广州川将机电设备有限公司的产品与服务，并支持后台内容管理。

## 线上地址

**https://chuanjiang-jidian.app.workbuddy.host/**

## 功能特性

- **四个前台页面**：首页、关于我们、产品服务、联系我们
- **产品服务**：按产品类型分类（灌装配件 / 分液分配 / 泵阀组件 / 传动配件 / 螺旋输送 / 输送理罐 / 计量分装），数据实时读取云端数据库
- **管理后台**：管理员邮箱登录，支持产品增删改、图片上传至云端存储
- **视觉风格**：深蓝 + 品牌红配色，响应式适配手机与电脑

## 技术栈

- **前端**：原生 HTML + CSS + JavaScript（单页应用，hash 路由，无框架依赖）
- **云端**：WorkBuddy 云服务（数据库 / 认证 / 对象存储）
- **云服务 SDK**：`@tencent-ai/workbuddy-cloud-sdk`（已本地化引入，不依赖外部 CDN）

## 本地运行

纯静态站点，任意静态服务器即可，例如：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

> 说明：云端数据库、登录、云存储仅在线上域名下可用（服务端做 Origin 校验），本地预览只能查看页面 UI 效果。

## 后台管理

- 访问 `#/admin` 进入管理后台
- 首次使用点「首次注册」，用邮箱验证码注册管理员账号
- 之后用「邮箱 + 密码」登录，即可增删改产品、上传产品图片
